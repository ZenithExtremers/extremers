# エクストリーマーズ

ランダムに出てくる人物から10秒以内に1人を選ぶのを4回くり返し、そろった4人で「究極の課題」に挑む対戦ゲームです。スマホで遊べるPWA（GitHub Pages）。

## 遊び方
1. 「設定」でGemini APIキーを入れる（Google AI Studioで無料で作れる。キーはこの端末の中にだけ保存）
2. 「CPUと対戦」「オンライン対戦」「2人で対戦（1台を回す）」のどれかを選ぶ
3. 毎巡5人の候補から10秒以内に1人選ぶ（時間切れはランダム）。相手のチームは4人そろうまで秘密
4. 究極の課題が発表され、3つの関門に挑む。各関門で作戦（方針）を選ぶ
5. 実行する人は、方針に向いている人ほど選ばれやすいランダム。サイコロ（1〜100）は各プレイヤーが自分で振る
6. 100点満点（第1・第2関門30点、最終関門40点）。多いほうの勝ち

- タイトル画面に「今日あと何ゲーム遊べるか」を表示。無料枠が1ゲーム分（5回）に満たないときは始められない（上限は設定で変更可、太平洋時間0時＝日本時間17時にリセット）
- 終わった対戦は「対戦ログ」に最大50件まで残る（この端末の中だけ。オンライン対戦も含む）

## オンライン対戦（Firebase）
- **ルーム**：「オンライン対戦 → ルームを作る」で5文字のコードができる。相手はコードを入れるか、送られたリンク（`?room=コード`）を開くと参加
- **リアルタイム対戦**：ドラフトは2人が同時に10秒で選ぶ。関門の作戦も同時に選び（60秒）、サイコロは各自が自分の端末で振る（25秒で自動）。相手の候補・弱点・作戦は画面に送られない
- **物語生成**：ルームを作った人（ホスト）の Gemini APIキー（無料枠）だけを使う。参加する人はキー不要。1試合で5回
- **ランキング**：オンライン対戦の結果でレート（はじめは1000、1試合で最大±40）が変わる。レート順・勝利数・フレンド内の3種類
- **フレンド**：6文字のフレンドコードで申請→相手が承認。🟢はいまアプリを開いている人。「招待」でルームが作られ、相手のタイトル画面に通知が出る
- **人物図鑑**：対戦で出会った人物が自動で登録される（CPU戦・2人対戦・オンライン対戦すべて）。「見かけた／仲間にした／勝利」の回数も記録。ログイン中はクラウドにもバックアップ
- アカウントは匿名ログイン（このブラウザにひも付く）。サイトのデータを消すと戦績も消える
- ホストが退出・リロードすると対戦は中止になる（ゲストはリロードしても同じ対戦に戻れる）

### オンライン対戦の準備（管理者が1回だけ・無料）
Firebase の無料プラン（Spark）だけで動きます。クレジットカードの登録は不要です。
1. https://console.firebase.google.com で「プロジェクトを作成」（Googleアナリティクスはオフでよい）
2. 「構築 → Authentication → 始める → ログイン方法」で **匿名** を有効にする
3. 「構築 → Firestore Database → データベースを作成」。ロケーションは `asia-northeast1`（東京）、**本番環境モード** で作成
4. Firestore の「ルール」タブに、このリポジトリの `firestore.rules` の中身を全部貼り付けて「公開」
5. 「プロジェクトの設定（歯車）→ 全般 → マイアプリ」で **ウェブ（</>）** を追加し、表示された `firebaseConfig` の中身を `firebase-config.js` の `window.FIREBASE_CONFIG = { ... }` に貼ってコミット
6. GitHub Pages に反映されたら、「オンライン対戦」ボタンから使える

- `firebase-config.js` の値は公開して大丈夫なもの（データの守りは `firestore.rules` で行う）。Gemini のキーは今まで通り各自の端末の中だけ
- 無料枠の目安：Firestore は1日に読み取り5万回・書き込み2万回まで。1試合はおよそ書き込み40回・読み取り80回程度なので、1日数百試合までは無料
- `firebase-config.js` が空のままなら、オンライン機能はオフになり、ほかの機能はそのまま使える

## サウンド
- BGMはWeb Audioでその場で合成（音声ファイルなし・著作権フリー）
- 場面：タイトル／ドラフト（残り3秒で加速）／関門（最終関門は激しく）／決着（勝ち・負け）
- ドラフトと関門の曲は、お題17種類それぞれに専用の曲（サーフロック、ケルトパンク、トラップ、こっそりジャズ、行進曲など）
- 効果音：サイコロ、成功・失敗、退場、タイマーの秒読み、ボタン
- 右上のボタンでミュート。設定でBGM・効果音の音量を変えられる

## ルールの中身
- 成功率：特技がぴったり80%／こじつけ50%／無関係20%。体を使う方針は運動神経で±10%ずつ
- 人物には弱点がある。実行役の弱点が作戦に引っかかると成功ライン−15。相手チームの弱点は対戦が終わるまで「？？？」で伏せる。弱点が引っかかる人は実行役に選ばれにくく（重み0.3倍）、加勢もしない
- 特技は毎巡、アプリがジャンル（運・知識・対人・感覚・変わった体質など25種）を5人に割り振ってからAIに作らせる
- 各関門の作戦には「妨害」（相手の成功ライン−25、自分も−10）と「共闘」（両チームが共闘を選べば双方+20。共闘を持ちかけた相手を妨害すると妨害側に+10）がある
- 失敗すると、30%の確率で実行した人が退場（最終関門を除く）
- 得点：成功は配点の60〜100%（余裕をもって成功するほど高い）、失敗は0〜30%（惜しいほど高い）
- サイコロの目はアプリが決める（AIは結果どおりに物語を書くだけ）
