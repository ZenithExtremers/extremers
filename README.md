# エクストリーマーズ

ランダムに出てくる人物から10秒以内に1人を選ぶのを4回くり返し、そろった4人で「究極の課題」に挑む対戦ゲームです。スマホで遊べるPWA（GitHub Pages）。

## 遊び方
1. 「設定」でGemini APIキーを入れる（Google AI Studioで無料で作れる。キーはこの端末の中にだけ保存）
2. 「CPUと対戦」か「2人で対戦（1台を回す）」を選ぶ
3. 毎巡5人の候補から10秒以内に1人選ぶ（時間切れはランダム）。相手のチームは4人そろうまで秘密
4. 究極の課題が発表され、3つの関門に挑む。各関門で作戦（方針）を選ぶ
5. 実行する人は、方針に向いている人ほど選ばれやすいランダム。サイコロ（1〜100）は各プレイヤーが自分で振る
6. 100点満点（第1・第2関門30点、最終関門40点）。多いほうの勝ち

- タイトル画面に「今日あと何ゲーム遊べるか」を表示。無料枠が1ゲーム分（5回）に満たないときは始められない（上限は設定で変更可、太平洋時間0時＝日本時間17時にリセット）
- 終わった対戦は「対戦ログ」に最大50件まで残る（この端末の中だけ）

## サウンド
- BGMはWeb Audioでその場で合成（音声ファイルなし・著作権フリー）
- 場面：タイトル／ドラフト（残り3秒で加速）／関門（最終関門は激しく）／決着（勝ち・負け）
- ドラフトと関門の曲は、お題17種類それぞれに専用の曲（サーフロック、ケルトパンク、トラップ、こっそりジャズ、行進曲など）
- 効果音：サイコロ、成功・失敗、退場、タイマーの秒読み、ボタン
- 右上のボタンでミュート。設定でBGM・効果音の音量を変えられる

## ルールの中身
- 成功率：特技がぴったり80%／こじつけ50%／無関係20%。体を使う方針は運動神経で±10%ずつ
- 人物には弱点がある。実行役の弱点が作戦に引っかかると成功ライン−15。相手チームの弱点は対戦が終わるまで「？？？」で伏せる。弱点が引っかかる人は実行役に選ばれにくく（重み0.3倍）、加勢もしない
- 特技は毎巡、アプリがジャンル（運・知識・対人・感覚・変わった体質など25種）を5人に割り振ってからAIに作らせる
- 各関門の作戦には「妨害」（相手の成功ライン−25、自分も−10）と「共闘」（両チームが共闘を選べば双方+20。共闘を持ちかけた相手を妨害すると妨害側に+10）がある
- 失敗すると、30%の確率で実行した人が退場（最終関門を除く）
- 得点：成功は配点の60〜100%（余裕をもって成功するほど高い）、失敗は0〜30%（惜しいほど高い）
- サイコロの目はアプリが決める（AIは結果どおりに物語を書くだけ）
