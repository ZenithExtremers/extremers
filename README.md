# エクストリーマーズ

ランダムに出てくる人物から3秒以内に1人を選ぶのを4回くり返し、そろった4人で「究極の課題」に挑む対戦ゲームです。スマホで遊べるPWA（GitHub Pages）。

## 遊び方
1. 「設定」でGemini APIキーを入れる（Google AI Studioで無料で作れる。キーはこの端末の中にだけ保存）
2. 「CPUと対戦」か「2人で対戦（1台を回す）」を選ぶ
3. 毎巡5人の候補から3秒以内に1人選ぶ（時間切れはランダム）。相手のチームは4人そろうまで秘密
4. 究極の課題が発表され、3つの関門に挑む。各関門で作戦（方針）を選ぶ
5. 実行する人は、方針に向いている人ほど選ばれやすいランダム。サイコロ（1〜100）は各プレイヤーが自分で振る
6. 100点満点（第1・第2関門30点、最終関門40点）。多いほうの勝ち

## ルールの中身
- 成功率：特技がぴったり80%／こじつけ50%／無関係20%。体を使う方針は運動神経で±10%ずつ
- 失敗すると、30%の確率で実行した人が退場（最終関門を除く）
- 得点：成功は配点の60〜100%（余裕をもって成功するほど高い）、失敗は0〜30%（惜しいほど高い）
- サイコロの目はアプリが決める（AIは結果どおりに物語を書くだけ）
